# Content Pattern Analysis — 方法论

本文档沉淀内容平台分析的核心方法论，适用于任何有公开数据的内容平台（小红书、知乎、微信公众号、微博、抖音、B站等）。

---

## 核心原则

**1. 定量发现 + 定性解释**

数据告诉你"是什么"，人要读才知道"为什么"。两者缺一不可。

**2. 避免单一维度**

高点赞 ≠ 好内容。高互动（评论/转发）的内容和纯高点赞的内容，往往是两套完全不同的规律。先想清楚创作者的目标是什么。

**3. 跨分段对比，不要只读爆款**

只分析 10w+ 赞的帖子会被产品流量带偏——很多爆款靠的是发布时机、达人转发、或者话题本身，不全是内容质量。要看"还不错"的帖子的真实规律。

**4. 先破坏再建设**

分析的第一步是推翻自己的假设。如果你的假设是"长文案更好"，先去低赞区找反例。

---

## 五步分析框架

### Step 1: 数据提取

从平台数据集或 API 提取原始数据，保存为本地文件（JSONL / CSV / Parquet）。

常用数据源：
- 平台官方 API（有速率限制）
- 第三方数据平台（千瓜、蝉妈妈、新榜等）
- HuggingFace Datasets（很多平台有现成的）
- 浏览器采集 — 使用 Agent 本身已配置的浏览器工具直接读取页面，无需 API key

核心提取字段：
```
id, title/text, likes/favorites, comments, shares, author, timestamp, url, tags
```

### Step 2: 定量发现

**点赞/收藏分布**

```python
# 伪代码
likes = [p['likes'] for p in posts]
print(f"范围: {min(likes)} - {max(likes)}")
for lo, hi in [(10000, 50000), (1000, 10000), (100, 1000)]:
    count = sum(1 for s in likes if lo <= s < hi)
    print(f"{lo}-{hi}: {count} 条")
```

找到平台特有的"门槛值"——比如小红书 1000 赞是个基础门槛，10000+ 才能进发现页。

**互动率 = 评论数 / 点赞数**

```python
for p in posts:
    p['engagement_rate'] = p['comments'] / p['likes'] if p['likes'] > 0 else 0
```

- > 0.1：高互动，引发讨论（知乎型平台常见）
- 0.01-0.1：正常
- < 0.01：内容吸引点赞但不吸引评论（小红书"好看但没话说"型）

**转发率 = 转发数 / 点赞数**

```python
for p in posts:
    p['share_rate'] = p['shares'] / p['likes'] if p['likes'] > 0 else 0
```

- 高转发率说明内容有传播价值（知乎、微信公众号常见）
- 低转发率说明内容只对个人有效（自拍、生活记录）

**正文长度 vs 点赞**

```python
short = sum(1 for p in posts if 0 < len(p['text']) <= 100)
medium = sum(1 for p in posts if 100 < len(p['text']) <= 500)
long = sum(1 for p in posts if len(p['text']) > 500)
```

对比不同分段的长度分布：爆款帖和普通帖的长度有什么不同。

### Step 3: 跨分段对比

设定对比分段（以小红书为例）：

| 分段 | 代表什么 | 样本量参考 |
|------|---------|-----------|
| 10w+ 赞 | 顶流，含资源助推 | 5-20 条 |
| 1w-10w 赞 | 正常爆款，可参考 | 50-200 条 |
| 1000-1w 赞 | 不错的帖子，竞争最激烈 | 500+ 条 |
| < 1000 赞 | 普通帖子 | 大多数 |

对比维度：
- 标题结构（疑问句 vs 陈述句 vs 感叹句）
- 正文长度
- 互动率 / 转发率
- 作者身份（素人 vs KOC vs KOL）
- 首图/封面类型
- 标签（tags）使用

### Step 4: 人工精读（采样）

每段取 20-30 条样本人工读。

读的时候问：
1. 这个帖子在说什么？一句话概括
2. 吸引我读下去的第一句话是什么？
3. 标题的 hook 是什么（痛点/好奇/利益/情感）？
4. 正文哪个段落最让我想互动？
5. 有什么让我想转发或收藏的点？

### Step 5: 模式合成

从人工精读中提炼结构化模式：

**模式描述模板**：

```
## 模式名称

**核心公式**：一句话概括这个模式的本质

**代表帖**（含链接）：
- [点赞] 标题 | 关键 hook

**为什么有效**：
- 第1点
- 第2点

**内容结构**：
1. ...
2. ...
3. ...

**适用场景**：
适合什么类型的内容创作者

**边界**：
什么时候这个模式会失效
```

## 各平台指标参考

| 平台 | 核心互动指标 | 高互动阈值 | 爆款门槛参考 |
|------|------------|-----------|------------|
| 小红书 | 点赞/收藏/评论 | eng_rate > 0.05 | 1000+ 赞 |
| 知乎 | 点赞/喜欢/评论 | eng_rate > 0.1 | 1000+ 赞 |
| 微信公众号 | 阅读量/在看/收藏 | 在看率 > 0.01 | 1w+ 阅读 |
| 微博 | 转发/评论/点赞 | 转发率 > 0.1 | 1w+ 转发 |
| B站 | 点赞/投币/收藏 | 点赞率 > 0.05 | 1w+ 播放 |

## 常见陷阱

**1. 把相关当因果**

"痛点开头"的帖子平均点赞高，不等于用痛点开头就一定能火。相关不等于因果。

**2. 忽视平台社区文化**

知乎用户重视深度和干货；小红书用户重视视觉和情感；B站用户重视内容和诚意。不存在万能公式。

**3. 样本选择偏差**

只读爆款帖 → 误以为爆款的特质就是成功原因。很多爆款的成功是因为达人转发、发布时机好，不只是内容好。

**4. 把点赞当作唯一成功指标**

如果创作者的目标是建立深度讨论，100 赞但 20 条评论的知乎帖可能比 1000 赞零评论的小红书帖更有价值。
